# Gemini API Chatbot

This is a beginner-friendly AI chatbot built using Python, Gradio and the Google Gemini API.

## What it does

The user types a question, and the app sends it to the Gemini API to generate a response.

## Tech used

- Python
- Gradio
- Google Gemini API
- Google AI Studio
- GitHub
- Hugging Face Spaces

## What I learned

- How to call an AI model using an API
- How to use an API key safely with a `.env` file
- How to build a chatbot interface using Gradio
- How to run an AI app locally
- How to prepare an AI app for GitHub and Hugging Face

## Local setup

Create a `.env` file and add:

GEMINI_API_KEY=your_api_key_here

Then run:

pip install -r requirements.txt
python app.py
